## 什么是LangChain

LangChain 是一个开源的 Python 库，用于构建 LLM 应用。包含以下特性

1. LLM统一接口和丰富的提示
2. 链（将工具串联起来）
3. LCEL表达式
4. 检索增强生产（RAG）
5. Agent
6. 模型记忆（memory）
